# 고정 좌우 출력 보정의 양쪽 동시 재생 예측 비교

입력은 `results\today_B_comparison_20261012_20261012_185129`의 2026-10-12 녹음과 기존 B 모델 설정이다. 새 보정값은 추정하지 않았다. B0(무보정), B1(공통 오른쪽 gain), B2(P02 단독 녹음으로 기존에 구한 대역별 gain)를 비교했다.

각 대역에서 기존 Butterworth 4차 `sosfiltfilt`로 좌우 모델 성분을 처리한 뒤 `왼쪽 + gain × 오른쪽` 파형을 합산해 에너지를 계산했다. 따라서 교차항을 포함하며, 단독 에너지의 단순 합으로 동시 재생 에너지를 대체하지 않았다. B2는 대역별 분석용이며 광대역 EQ/WAV는 만들지 않았다.

`comparison.csv`에 지점·대역·시작/종료·모델별 I, signed error, absolute error를 저장했고, `metrics.json`에 P01·P03 8개 항목의 시작/종료별 MAE/RMSE와 B0 대비 개선·악화를 저장했다. P02는 별도 보고이며 보정 평가에 포함하지 않았다.

시작·종료 비교는 기준 구간 선택에 대한 민감도 확인이며 신뢰구간이나 오차 상·하한이 아니다. 파일 간 재생·녹음 조건 변화 가능성이 있다. 극성·지연 탐색 및 P01/P03 기반 재보정은 수행하지 않았다. 기존 호환 캐시가 없어 필요한 B RIR/파형 계산을 수행했으며 설정은 `settings.json`에 기록했다.
