# P01 양쪽 시작·종료 변화 분석

기존 정렬 위치와 중앙 8초를 재사용했다. 전체 파일에 4차 Butterworth bandpass + sosfiltfilt를 적용한 뒤 각 중앙 8초를 1초씩 비교했다. 원본 수정, 음량 정규화, 소음 제거, 모델 보정, 극성/지연 탐색, RIR 재계산은 하지 않았다.

현장 관찰: “현장에서 왼쪽 스피커가 오른쪽보다 크게 들렸음.” 이는 청취 관찰이며 스피커 자체 출력 차이를 확정하지 않는다. AGC, 앰프 조절, 위치 변화, 주변 소음 중 어느 것도 이 자료만으로 원인으로 단정하지 않는다.
