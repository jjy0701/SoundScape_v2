작성 기준: 2026-09-19

이 문서는 기존 원본 녹음, 07번 측정조건, 08번 실행 결과와 기존 2D 학습·검증·테스트 분할을 변경하지 않고, 다음 비교 단계의 기준을 고정하기 위한 작업 메모입니다.

인수인계 문서와 08번 JSON이 기록한 `테스트 녹음 2.wav`의 SHA-256은 `0b4fe722...d6a3ded7ab`이며, 현재 작업 폴더의 `실험.wav` 해시는 별도입니다. 따라서 `실험.wav`를 문서상의 P02 파일과 동일하다고 덮어쓰거나 이름을 바꾸지 않습니다.

## 측정값과 시뮬레이션 가정

### 측정·기록으로 취급할 값

- 방 잠정 치수: 7.50 × 10.25 × 2.63 m
- 잠정 음원 위치: S_L=(0.52, 3.10, 2.50), S_R=(6.55, 3.10, 2.50) m
- P02 잠정 위치: (3.75, 5.00, 0.706) m
- `실험.wav`: 16 kHz, mono, 약 72.18초, 기준 신호 후보 3개
- 후보 중앙 구간 RMS: -38.6050, -38.5715, -38.5934 dBFS; 반복 최대–최소 0.0335 dB

위 dBFS는 디지털 full-scale 기준이며 dB SPL이 아닙니다. 반복 안정성은 확인할 수 있지만 AGC가 꺼졌다는 증거는 아닙니다.

### 08번에서 가정한 값

- fs=48 kHz, 음속=343 m/s, 반사 차수=32 (비교 16)
- 벽·바닥·천장 에너지 흡음률=0.2, 주파수 무관
- 두 음원 무지향성, 상대 gain 1.0/1.0, 추가 지연 0 samples, 동일 극성
- 가구·회절·공기 흡음·스피커/휴대폰 주파수 응답·환경소음·AGC 미반영

따라서 08번 원시 진폭은 Pa나 dB SPL이 아니며, P02 녹음의 dBFS와 바로 뺄 수 없습니다.

## 08번 계산 결과의 해석

- 직접음 시간 검사: S_L 4.1547 m / 12.113 ms, S_R 3.8299 m / 11.166 ms; 둘 다 PASS.
- 두 음원 파형을 각각 컨볼루션한 뒤 시간·부호를 보존하여 합산했으며, 선형성 검사 최대 차이는 약 1.73e-16.
- 반사 차수 16→32의 P02 합성 레벨 변화는 지정한 세 시험 구간에서 +0.1610 dB.
- 이는 구현 검사와 해당 조건의 민감도 결과이지, 실측과의 오차나 전 공간의 수렴 증명이 아니다.

## 다음 비교 절차

1. 실제 P02 파일의 원본 경로와 SHA-256을 사용자 기록으로 확정한다. 현재 `실험.wav`는 복사·개명하지 않는다.
2. 재생 원본, 녹음 sample rate, 시작 지연을 확인하고, 48 kHz 원본과 16 kHz 녹음이면 공통 분석 대역을 명시한다.
3. 녹음에서 기준 신호 후보별로 동일한 8초/10초 구간을 추출하되, 원본 PCM은 수정하지 않고 파생 분석 파일만 `results/classroom_3d/measurement/P02/` 아래에 저장한다.
4. 절대 레벨 비교 전, 먼저 반복별 파형 정렬·상관·주파수별 에너지·잔향 꼬리 지표를 비교한다.
5. dBFS↔모델 진폭의 절편을 임의로 맞추지 않는다. 보정용 기준음/마이크 감도/재생 체인 정보가 없으면 상대 파형·대역 지표까지만 보고한다.
6. P01/P03 녹음이 생기면 같은 원본과 조건을 사용하고, 기존 P02 분석을 새 test 분할이나 2D AI 평가에 섞지 않는다.

## 비교 전에 필요한 현장 기록

실제 receiver 좌표와 높이, 켠 스피커 수, PC·플레이어·앰프 음량, 휴대폰 방향과 녹음 앱 처리(AGC/소음 억제), 사람·HVAC·문/창문 상태, 가구 배치를 기록해야 합니다. 이 정보가 없으면 결과는 “가정한 3D 모델과 한 녹음의 조건부 파형 비교”로만 표현합니다.
